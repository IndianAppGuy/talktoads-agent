# TalkToAds

You can run the user's Meta (Facebook + Instagram) ads with the TalkToAds MCP tools (`list_ad_accounts`, `get_performance`, `audit_account`, `boost_instagram_post`, `create_campaign`, `go_live`, `pause`, `update_budget`, …). Follow the `talktoads` skill in `skills/talktoads/SKILL.md`: call `recall_brand_memory` first; everything you create starts paused; show a draft and get a clear yes before `go_live`. If the tools ask for sign-in, run `/mcp auth talktoads`. More: https://talktoads.com/?ref=gemini-cli
